# Gi AI Landing Page

A modern landing page for Gi AI, an AI-powered tool for analyzing YouTube comments and generating actionable insights. Built with React and Vite, featuring interactive scroll animations and dark mode support.

## Features

- Interactive demo with scroll-hijacked animations
- AI-powered YouTube comment analysis simulation
- Responsive design for desktop and mobile
- Dark mode with automatic theme detection
- Matrix rain background animation
- Export functionality for multiple formats (PDF, HTML, Markdown, CSV)
- Real-time progress tracking and statistics visualization

## Tech Stack

- React 19
- Vite
- Tailwind CSS 4
- Framer Motion
- GSAP ScrollTrigger
- React Router DOM
- Lucide React

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/andrea16martina/giai-landing.git
   cd giai-landing
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open http://localhost:5173 in your browser.

### Build

```bash
npm run build
```

## Usage

The landing page features an interactive demo that walks through the Gi AI analysis process:

1. Enter a YouTube URL
2. Select analysis topics
3. Watch the progress animation
4. View statistics and charts
5. Export results

The demo uses scroll-triggered animations to create an engaging user experience.
